# LIMITATIONS

- Only OpenCode has an operational **Certified** adapter. All other harnesses
  are **Adapter Ready** — their support is not yet operationally proven.
- An adapter existing does not mean all ECC capabilities are active on that
  harness (e.g., agent selection, review comments and UI are declared
  unsupported on the OpenCode adapter).
- Institutional `autonomous-safe` repairs are executed only in an explicitly
  authorized disposable project; no production code is mutated.
- This repository is an integration layer; it is not the Better Harness
  upstream and does not replace the ECC runtime.
