# ATTRIBUTION

## Better Harness

The **Better Harness** analysis methodology — including its five dimensions and
reporting model — originates from:

- Repository: https://github.com/QoderAI/better-harness
- License: MIT (upstream)
- Authorship: preserved; the upstream authors own the methodology.

This project **implements only integration**: it connects Better Harness
analysis to institutional governance. It does not fork, modify, redistribute or
substitute Better Harness, and it does not copy protected upstream files.

## ECC institutional runtime

Institutional governance (WorkflowExecutor, E3 Write Contract, E4 same-session
correction, U6 certification, EventStore, GraphStore, OPS) belongs to the **ECC
institutional runtime**, consumed through its public API. This repository does
not duplicate or reimplement those authorities.

## OpenCode

OpenCode is the execution harness. In this repository it appears **only** as
the first certified adapter — one of many possible harnesses.
